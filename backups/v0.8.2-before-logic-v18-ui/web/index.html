Help
使用说明
按以下顺序即可开始多平台同步输入。
1. 在左侧选择 Edge、Chrome 或夸克，并确认程序路径。
2. 勾选需要使用的 AI 平台，点击“一键拉起已选平台”。
3. 在中间输入内容，可添加最多 5 个附件。
4. 点击“AI 模式”，分别设置各平台本次使用的模式。
5. 点击“发送到已选平台”，并在右侧查看附件上传、模式切换和回复状态。

若平台账号不具备某个模式，或网页结构发生变化，程序会提示需要人工选择。切换浏览器时不会重复发送上一条内容。
