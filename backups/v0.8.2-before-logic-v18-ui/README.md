# 多平台 AI 同步输入器

Windows 桌面端初版。默认包含：Claude、ChatGPT、Grok、Google Gemini、DeepSeek、豆包、千问。

## 使用方法

1. 双击 `多平台AI同步输入器.exe`，程序会以桌面应用窗口显示主界面。
2. 先选择本次用于打开 AI 平台的浏览器：Edge、Chrome 或夸克。
3. 勾选本次要使用的平台。
4. 点击“一键拉起已选平台”，程序会在当前浏览器中打开全部已选 AI。
5. 在“统一输入”区域输入内容；如有需要，可上传附件并为每个平台选择 AI 模式。
6. 点击“发送到全部已选平台”，程序会先切换模式、上传附件，再提交统一内容。
7. 首次使用某个平台时，如登录状态未能导入，请在选中的浏览器中登录账号。
8. 登录或验证完成后，在程序中点击该平台的“重试”。
9. 程序会分别显示“已打开、正在上传附件、正在输入、生成中、已完成、需人工处理、失败”等状态。

## 初版能力

- 7 个平台默认配置并可单独开关。
- 支持用户自行添加其他 AI 平台：填写名称和完整聊天页面网址后，会保存到平台列表，可勾选、一键拉起、统一发送和删除。
- 自定义平台默认使用通用网页识别规则；页面结构特殊时会显示“需人工处理”，需要再增加专用适配规则。
- 支持 Edge、Chrome、夸克、360 浏览器四种启动浏览器，默认选择第一个已检测到的浏览器。
- 三种浏览器都会优先自动检测标准安装路径；也可以在界面中填写浏览器主程序的完整 `.exe` 路径，并随时恢复自动检测路径。
- 主界面、历史记录、添加平台、设置和确认提示统一采用浅色 Logic 科技风；设置中可控制浏览器切换确认、新平台自动选中和回复预览密度。
- Edge、Chrome、夸克、360 浏览器及内置 AI 平台使用独立品牌图标；ChatGPT 使用 OpenAI 官方 Blossom 轮廓。
- 0.6.0 使用用户提供的十张官方图标原图作为内置资源，并按确认稿恢复左侧列表、中间输入区、右侧七平台状态卡的三栏排版。
- 0.6.1 修正 Claude 下方放射线与 DeepSeek 上方鲸尾的图标裁切范围，并按确认稿统一系统图标与中文字体。
- 0.6.2 对顶部与底部设置齿轮进行 1 像素光学校正，使图标视觉中心与文字严格对齐。
- 0.6.3 按参考图重新绘制设置图标，采用更小的八齿细线轮廓与清晰中心圆。
- 0.7.0 将原“导入文本”改为真正的多附件上传，支持每次最多 5 个、单个不超过 20 MB；新增七个平台各自独立的 AI 模式选择与自动切换提示。
- 0.8.0 新增逐平台登录状态与实际可用模式检测；删除右上角控制按钮并将右侧状态栏向上扩展；选中 1–4 个平台时，状态卡会自动均分并填满整个预览区域。
- 0.8.1 修复 5–7 个平台未铺满右侧状态栏的问题；状态卡在空间足够时自动等分铺满、空间不足时才滚动；浏览器选择改为 2×2，并新增 360 安全/极速浏览器默认路径检测及自定义路径。
- 0.8.2 将左下控制栏下沉并与中间发送操作带对齐；状态统计移到“实时状态”标题右侧；右下加入“Design by Logic”签名；360 浏览器改用用户提供的官方图标。
- 运行途中可以切换浏览器；切换时停止当前任务，并在新浏览器中重新打开全部已选平台。
- 提供“一键拉起已选平台”，只打开页面而不发送内容。
- 首次使用每个浏览器时，自动把该浏览器最近使用的个人资料登录会话导入程序专用资料。
- 同一内容并行发送到已选平台。
- 附件先上传到本机临时缓存，再分别传入所有已选 AI；不会上传到程序开发者的服务器。
- 各平台可单独选择默认、快速、思考、Pro、联网搜索等可用模式；平台页面或账号权限不支持时会提示人工处理。
- 每个平台独立运行，单个平台失败不影响其他平台。
- 实时显示状态、耗时和回复预览。
- 支持打开平台、停止、重试和复制完整回复。
- 保存最近 100 条提问历史。
- 使用独立浏览器资料目录保存登录状态，不保存账号密码。

## 重要说明

- 网页结构会随平台更新，某个平台如果无法自动定位输入框，会显示“需人工处理”。
- 添加自定义平台时应填写可以直接进行对话的页面网址，而不是官网首页或下载页面。
- 程序不会绕过验证码、人机验证或登录保护。
- 请遵守各平台的服务条款和账号使用限制。
- 切换浏览器时不会自动重复发送正在执行的提问，避免产生重复任务；切换完成后请重新点击发送。
- Edge、Chrome、夸克、360 浏览器分别保存独立登录状态；退出程序时会关闭由程序启动的受控浏览器。
- 程序不会直接操作日常浏览器正在使用的原始个人资料，避免文件锁冲突或资料损坏。若登录会话导入失败，请关闭对应的普通浏览器并重新启动本程序再试。
- 夸克使用公共桌面快捷方式所指向的 `C:\Program Files\Quark\quark.exe` 和相同桌面启动参数，同时保留自动输入控制能力。
- 当前检测到的夸克标准路径为 `C:\Program Files\Quark\quark.exe`。若安装位置不同，选择“夸克”后粘贴实际 `quark.exe` 路径并点击“保存路径”。
- 历史和浏览器登录数据保存在 `%LOCALAPPDATA%\MultiAIInput`。

## 从源码启动

需要 Python 3.10+、Playwright，以及本机安装的 Edge、Chrome 或夸克浏览器：

```powershell
python app.py
```
