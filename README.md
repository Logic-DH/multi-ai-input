# 多平台Ai同步输入器

**V1 · Windows 桌面工具**

一次输入，将同一问题发送到多个 AI 网页，在同一个窗口查看各平台的状态和回复，减少重复复制、粘贴和切换页面。

本项目通过本机浏览器操作各平台网页，需要用户自己的平台账号及相应服务权限。

## 当前功能

- 默认配置 Claude、ChatGPT、Grok、Google Gemini、DeepSeek、豆包、千问、Kimi、智谱清言，并支持添加自定义平台。
- 支持 Edge、Chrome、夸克、360 浏览器；自动检测桌面快捷方式和常见安装路径，也可手动设置程序路径。
- 勾选平台后统一打开、并行发送文本；单个平台可以停止、重试、打开原页面和复制回复。
- 支持上传附件，也支持直接粘贴截图、图片或复制的文件；每次最多 5 个附件，单个不超过 20 MB，实际可用类型及大小还受目标平台限制。
- 检测页面、登录、输入能力和可用 AI 模式；集中展示任务状态、耗时与回复，支持列表和并排视图及展开查看。
- 保存最近 100 条提问历史；提供结构化运行日志和诊断包导出。

## 安装与运行

### 使用 Windows 程序

如果仓库的 **Releases** 中已发布 V1 安装包或可执行文件，可下载对应文件并运行。源代码 ZIP 不能直接当作 Windows 程序使用。

### 从源码运行

需要 Windows、Python 3.10 或更高版本，以及本机安装的受支持浏览器。Edge 可用于桌面应用窗口；未检测到 Edge 时，主界面回退为系统默认浏览器页面。

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

程序使用检测到的本机浏览器，不需要为了正常运行另行下载 Playwright 自带的 Chromium。

## 使用步骤

1. 选择已安装的浏览器；自动识别失败时，在设置中填写浏览器主程序路径。
2. 勾选要使用的平台，点击“一键拉起已选平台”。
3. 在平台网页中完成登录或验证，返回程序重新检测或重试。
4. 输入问题，按需添加附件，并选择页面实际可用的 AI 模式。
5. 点击发送，在回复区查看各平台进度和结果。
6. 需要时复制、展开回复，或打开原平台页面继续操作。

切换浏览器会停止当前任务，并在新浏览器中重新打开平台；原问题不会自动重复发送。

## 数据与隐私

- 默认数据目录：`%LOCALAPPDATA%\MultiAIInput`，用于保存配置、历史、独立浏览器资料和运行日志。
- 首次受控启动浏览器时，程序会尝试从本机浏览器资料导入登录会话，后续使用独立资料保存登录状态；导入失败时需要手动登录。
- 程序保存的浏览器会话可能包含敏感登录信息，提问历史也可能包含个人内容，请勿上传数据目录、浏览器资料或诊断文件到公开仓库。
- 问题和附件会发送到你选择的 AI 平台，适用各平台的数据处理规则。
- 日志设计为不记录提示词、完整回复、Cookie、令牌、授权头和附件内容，并对路径与 URL 脱敏。分享诊断包前仍应自行检查。
- 日志默认位于 `%LOCALAPPDATA%\MultiAIInput\logs\runtime.jsonl`；详细说明见[运行日志与排查指南](docs/运行日志与排查指南.md)。

## 常见问题

**为什么提示“需人工处理”？** 可能遇到登录失效、验证码、地区限制、账号权限或网页结构变化。请在原平台页面确认原因；程序不会绕过平台验证和访问限制。

**自定义平台是否一定能发送？** 自定义平台使用通用网页识别规则；特殊页面可能需要专用适配器。内置平台也会受网页更新和账号权限影响。

**为什么没有显示某个 AI 模式？** 模式来自当前网页检测结果，不代表所有账号都能使用。订阅和权限以平台实际页面为准。

**关闭程序会影响浏览器吗？** 程序退出时会关闭它启动的受控浏览器。日常浏览器原始资料不作为直接控制目录。

## 开发与构建

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Python .\.venv\Scripts\python.exe
```

输出：`dist/MultiAIInput-V1.exe`。源码仓库排除 EXE 和构建目录，可执行文件建议放在 GitHub Releases。

基础自检请使用隔离数据目录，避免写入日常配置：

```powershell
$env:MULTIAI_DATA_DIR = Join-Path $env:TEMP ("MultiAIInput-selftest-" + [guid]::NewGuid())
.\.venv\Scripts\python.exe app.py --self-test
Remove-Item Env:MULTIAI_DATA_DIR
```

`tests/` 包含本地逻辑、日志和浏览器检查脚本。浏览器及外部平台检查需要对应运行环境；本地自检通过不代表所有平台在线发送路径均已通过。
