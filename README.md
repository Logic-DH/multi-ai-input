# 多平台 AI 同步输入器

Windows 桌面端初版。默认包含：Claude、ChatGPT、Grok、Google Gemini、DeepSeek、豆包、千问、Kimi、智谱清言。

## 使用方法

1. 双击 `多平台AI同步输入器.exe`，程序会以桌面应用窗口显示主界面。
2. 先选择本次用于打开 AI 平台的浏览器：Edge、Chrome、夸克或 360 浏览器。
3. 勾选本次要使用的平台。
4. 点击“一键拉起已选平台”，程序会在当前浏览器中打开全部已选 AI。
5. 在“统一输入”区域输入内容；图片、截图和文件可直接粘贴进输入框，也可点击“上传附件”，并可为每个平台选择 AI 模式。
6. 点击“发送到全部已选平台”，程序会先切换模式、上传附件，再提交统一内容。
7. 首次使用某个平台时，如登录状态未能导入，请在选中的浏览器中登录账号。
8. 登录或验证完成后，在程序中点击该平台的“重试”。
9. 程序会分别显示“已打开、正在上传附件、正在输入、生成中、已完成、需人工处理、失败”等状态。

## 初版能力

- 9 个平台默认配置并可单独开关。
- 支持用户自行添加其他 AI 平台：填写名称和完整聊天页面网址后，会保存到平台列表，可勾选、一键拉起、统一发送和删除。
- 自定义平台默认使用通用网页识别规则；页面结构特殊时会显示“需人工处理”，需要再增加专用适配规则。
- 支持 Edge、Chrome、夸克、360 浏览器四种启动浏览器，默认选择第一个已检测到的浏览器。
- 四种浏览器都会优先搜索当前用户桌面、OneDrive 桌面及公共桌面的快捷方式或 `.exe`，并解析快捷方式指向的真实程序；桌面未找到时再检测本机标准安装目录。用户也可以填写浏览器主程序的完整 `.exe` 路径，并随时重新自动检测当前电脑。
- 主界面保留产品原有结构：左侧集中控制浏览器与平台，中央并排展示各 AI 回复，底部统一输入；视觉采用低饱和中性色、轻量边框和克制阴影，设置中可控制浏览器切换确认、新平台自动选中和回复预览密度。

## 重要说明

- 网页结构会随平台更新。程序会分别显示页面状态、账户状态、输入能力、AI 模式和任务进度；无法定位输入框、遇到地区限制或验证页面时会明确显示对应原因。
- 添加自定义平台时应填写可以直接进行对话的页面网址，而不是官网首页或下载页面。
- 程序不会绕过验证码、人机验证或登录保护。
- 请遵守各平台的服务条款和账号使用限制。
- 切换浏览器时不会自动重复发送正在执行的提问，避免产生重复任务；切换完成后请重新点击发送。
- Edge、Chrome、夸克、360 浏览器分别保存独立登录状态；退出程序时会关闭由程序启动的受控浏览器。
- 程序不会直接操作日常浏览器正在使用的原始个人资料，避免文件锁冲突或资料损坏。若登录会话导入失败，请关闭对应的普通浏览器并重新启动本程序再试。
- 夸克使用公共桌面快捷方式所指向的 `C:\Program Files\Quark\quark.exe` 和相同桌面启动参数，同时保留自动输入控制能力。
- 若桌面和标准安装目录都没有检测到夸克，选择“夸克”后粘贴该电脑实际的 `quark.exe` 路径并点击“保存路径”。
- 历史和浏览器登录数据保存在 `%LOCALAPPDATA%\MultiAIInput`。

## 运行日志与诊断

- 日志位于 `%LOCALAPPDATA%\MultiAIInput\logs\runtime.jsonl`，采用每行一个 JSON 事件的结构化格式。
- 单文件 5 MB，最多 5 个备份，超过 14 天的备份会在启动时清理；默认记录 `INFO` 及以上级别。
- 需要详细排查时可在启动前设置 `MULTIAI_LOG_LEVEL=DEBUG`。
- 日志不会写入提示词、AI 完整回复、Cookie、令牌、授权头或附件内容；路径和 URL 会脱敏。
- 在“设置”中点击“导出诊断日志”，可生成包含轮转日志、脱敏环境信息和状态摘要的 ZIP。
- 完整字段说明和排查步骤见 `docs/运行日志与排查指南.md`。

python app.py
